# **Список лабораторных работ**

Данный документ содержит полный перечень лабораторных работ, направленных на поэтапное создание собственного языка программирования и виртуальной машины. Каждый этап добавляет новый слой архитектуры в классический пайплайн компилятора.

### **Лабораторная работа №1: Лексический анализ (Lexer / Scanner)**

**Цель:** Преобразование исходного текста программы в поток значимых лексем (токенов).

* **Ключевые концепции:** Токенизация, выделение ключевых слов, распознавание чисел и строк, пропуск незначащих символов (пробелы).  
* **Алгоритмы:** Жадный алгоритм поглощения символов (Maximal Munch).  
* **Результат:** Программа умеет читать текст и выдавать массив структур Token.

### **Лабораторная работа №2: Синтаксический анализ (Parser)**

**Цель:** Проверка грамматики и построение Абстрактного Синтаксического Дерева (AST).

* **Ключевые концепции:** Выражения (Expressions) и Инструкции (Statements), контекстно-свободные грамматики.  
* **Алгоритмы:** Рекурсивный спуск (Recursive Descent), обработка приоритета и ассоциативности математических и логических операторов.  
* **Результат:** Массив токенов преобразуется в иерархическое дерево узлов, готовое к анализу и исполнению.

### **Лабораторная работа №3: Семантический анализ (Semantic Analyzer)**

**Цель:** Статический анализ кода до этапа его выполнения.

* **Ключевые концепции:** Таблицы символов, проверка типов (Type Checking), контроль инициализации переменных.  
* **Алгоритмы:** Статический обход дерева (Visitor).  
* **Результат:** Компилятор научился выдавать ошибки несовпадения типов, предупреждения (Warnings) об использовании необъявленных переменных и находить "мертвые души" (переменные, которые объявлены, но не используются).

### **Лабораторная работа №4: Интерпретатор и Исполнение (Runtime)**

**Цель:** Разработка виртуальной машины для выполнения AST-дерева.

* **Ключевые концепции:** Среда выполнения (Runtime Environment), динамическая типизация, управление потоком выполнения (if, while).  
* **Алгоритмы:** Прямой обход дерева (Tree-Walk Interpreter), ленивые вычисления логических операторов (&&, ||).  
* **Результат:** Программа умеет вычислять математику, исполнять циклы и выводить результаты в консоль (print).

### **Лабораторная работа №5: Функции и Стек вызовов**

**Цель:** Внедрение модульности, поддержки пользовательских функций и рекурсии.

* **Ключевые концепции:** Вызовы функций, аргументы и параметры, возврат значений (return).  
* **Алгоритмы:** Создание изолированных стековых фреймов (областей памяти) для каждого вызова, проброс значений наверх дерева через системные исключения (Exception).  
* **Результат:** Язык поддерживает рекурсивные вызовы (например, вычисление факториала или чисел Фибоначчи) без утечек памяти между областями видимости.

### **Лабораторная работа №6: Middle-end и Оптимизация AST**

**Цель:** Ускорение работы программы путем преобразований кода на этапе компиляции.

* **Ключевые концепции:** Оптимизатор AST (Tree Rewriter).  
* **Алгоритмы:** Свертывание констант (Constant Folding) — вычисление статических математических выражений и конкатенации строк до рантайма; Устранение мертвого кода (Dead Code Elimination) — удаление недостижимых веток дерева.  
* **Результат:** Интерпретатор получает сжатое, предвычисленное дерево, экономя такты процессора на циклах.

### **Лабораторная работа №7: Массивы и структуры данных**

**Цель:** Добавление возможности работы с коллекциями данных.

* **Ключевые концепции:** Индексация, чтение и запись элементов по смещению.  
* **Алгоритмы:** Расширение парсера узлами ArrayExpression, IndexExpression, IndexAssignExpression.  
* **Результат:** Язык становится пригодным для написания сложных алгоритмов обработки данных (например, пузырьковой сортировки).
