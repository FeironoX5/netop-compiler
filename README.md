# netop-compiler

`netop-compiler` - учебный компилятор и виртуальная машина для языка на основе командного синтаксиса моего проекта [netop](https://github.com/FeironoX5/netop).

```text
[путь:]команда [аргументы...]
```

Файлы имеют расширение `.netop`. Сегменты пути разделяются `:`, аргументы - пробелами, комментарии начинаются с `#`.

## команды

- `var:let name [expr]`: Объявить/инициализировать переменную.
- `var:set goal expr`: Присвоить значение переменной или элементу массива.
- `io:print expr`: Вывести значение.
- `flow:if cond`: Начать условную ветвь.
- `flow:else`: Начать альтернативную ветвь.
- `flow:while cond`: Начать цикл.
- `flow:end`: Завершить условие или цикл.
- `fn:define name [params...]`: Объявить функцию.
- `fn:return [expr]`: Вернуть значение из функции.
- `fn:end`: Завершить объявление функции.

Остальные команды считаются командами netop: они сохраняются в AST и передаются исполнителю без изменения. По умолчанию виртуальная машина выводит их в стандартный поток, но интерфейс позволяет подключить обработчик сервера.

Выражения поддерживают числа, строки, логические значения, массивы, индексацию, вызовы функций, арифметику, сравнения и ленивые операторы `&&` и `||`. Встроенная функция `length(val)` возвращает длину строки или массива.

## пример

```
fn:define sum items
  var:let result 0
  var:let i 0
  flow:while i < length(items)
    var:set result result + items[i]
    var:set i i + 1
  flow:end
  fn:return result
fn:end

var:let values [3, 1, 2]
io:print sum(values)
```

## запуск

```text
bun src/cli.ts <command> <filename.netop>
```

- `tokens`: Вывести поток токенов.
- `ast`: Вывести синтаксическое дерево.
- `check`: Выполнить семантическую проверку.
- `optimize`: Вывести оптимизированное дерево.
- `run`: Выполнить программу.
